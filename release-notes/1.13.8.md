# Hail 1.13.8

**Add all apps to Home screen now creates separate app shortcuts, one at a time.**

- Replace the Settings grid action with individual launcher icons that retain Hail's unfreeze-and-open behavior.
- Add an optional **Hail shortcut assistant**. Enable it once in Android Accessibility settings; then one tap starts automatic placement on supported launcher confirmation screens.
- Keep one request in flight and verify its approval and completion before adding the next app.
- Show batch progress with pause, cancel, resume, retry, and manual continuation controls. Already-pinned IDs are skipped.
- Save progress across interruption or process loss. Recovery waits for an explicit Resume, and timeouts do not silently create duplicate requests.
- Pause automatic placement when the screen locks, the launcher changes, the assistant disconnects, or a confirmation cannot be identified safely.
- Preserve existing individual shortcuts and previously placed widgets. The bulk Settings button creates individual icons.

Android requires the one-time Accessibility permission. Launchers with protected or unsupported confirmation screens require manual approval; Hail does not guess coordinates or edit launcher databases.

The dark-grey theme, quiet freeze/unfreeze actions, inline risk guidance, yellow system-app names, and red unsafe/core-app names from 1.13.7 remain included.

The release uses the existing fork signing certificate for in-place updates.
