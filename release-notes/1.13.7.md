# Hail 1.13.7

Hail now uses a consistent dark-grey theme, gives app risk guidance directly in the Apps list, and puts all launchable apps in one home-screen grid.

## Quiet app actions

- Remove routine freeze/unfreeze and enable/disable success popups, the system-app filter warning, and the “Inactive here” caption.
- Show action failures in a scrollable inline panel with the affected package and reason. Explicit app controls and Android permission requests remain available.
- Keep app launches, tagging, backup and system-app disable/enable behavior intact.

## App risk guidance

- Show Recommended, Caution, Risky, Unsafe or Unknown on the Apps tab, with expandable explanations directly in each row.
- Display system app names in yellow. Display unsafe/core/essential apps in red, including frozen and selected entries.
- Use an offline UAD-ng community snapshot covering 5,399 exact package names, with current launcher, keyboard, device administrator and Android core checks taking precedence.
- Unknown is not a safety rating. Community removal guidance is advisory: dependencies differ by device, Android version and working mode.

## Home-screen grid and shortcut recovery

- Replace the per-app batch confirmation flow with **Add all-apps grid to Home screen**. One launcher placement request adds a resizable, scrollable grid containing all launchable apps in the current Android profile.
- Tap an icon to use Hail’s existing unfreeze-and-launch behavior. Existing individual shortcuts remain supported.
- Rebind widgets after restoration and refresh after reboot, Hail updates and package changes. Preserve individual shortcut IDs while refreshing their metadata.
- Add **Refresh Home screen shortcuts** in Settings. If a launcher erases its layout or data, Hail explains how to add the full grid again.
- Android controls launcher placement. The grid is one widget, not hundreds of independent desktop icons; Android does not provide a portable one-confirmation API for those icons.

## Dark-grey appearance

- Use neutral dark-grey backgrounds, surfaces and system bars throughout Hail, with readable light text and yellow/red risk colors.
- Keep the same dark resources when a launcher or phone uses light mode. Settings shows the fixed Dark grey appearance.

The release uses the existing Hail fork signing certificate so it can update previous releases in place.
