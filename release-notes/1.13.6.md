# Hail 1.13.6

Long-press a system app in **Apps** and choose **App status and controls**. Hail reads its status in the current Android profile. With Shizuku running and Hail authorized, eligible preinstalled apps can be disabled and enabled here or from Home. The direct Disable and Enable actions are still available on installed apps in a disable working mode.

- Show retained system packages visible to Shizuku in the Apps list. When Android permits it, Hail can change their stored enabled setting while they stay uninstalled for the current profile.
- Confirm a retained package’s enabled setting after a change. If Android cannot confirm it, Hail reports the result as unconfirmed. The status dialog also explains when Shizuku needs to be started or authorized.
- Check installed apps when deciding whether to run the automatic freeze service. Retained package records no longer keep it running.
- Report an APK export failure when the selected document provider cannot open an output stream.

Shell-backed Shizuku requests Android’s user-disabled state. Root-backed Shizuku requests full disable. Android can refuse changes to protected packages or to packages already in a state the shell cannot change. Hail reports those refusals.
